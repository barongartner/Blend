# Blend

A personal AutoMix for the Mac: pick songs from your Apple Music playlists (or
drop in MP3s), put them in order, set exactly where each one starts and ends,
and Blend renders one continuous DJ-style mix — beat-matched, tempo-synced,
with proper transitions — as a WAV or MP3 for the background of a video.

The mix length updates live as you edit, so you can match it to the video
before you render. All the analysis (beats, tempo, key, loudness) runs on this
Mac; nothing leaves it and no API is involved.
